# 1.0.4 — 抖音取流容错、中继时间线代际、弹幕恢复与工作台闭环

- **抖音媒体重定向**：拒绝改为结构化诊断（规则/阶段/脱敏主机/状态码），日志与遥测不再只给一句通用提示；补齐常见 CDN 家族，允许受控的 http→https 升级，初始终址与逐跳重定向仍走同一公网/私网/凭据校验。
- **抖音房间页**：全局请求闸门（2 并发、相邻 250 ms、排队上限 4 秒）→ pinned IPv4 优先 → 系统解析回退 → 最多 5 跳受控重定向 → 空壳 roomStore 页单次重试 → 连续空壳 6/12/18 秒冷却；每次请求补新 `__ac_nonce` 再接已保存 Cookie，兼容 `self.__pace_f` / `self.__next_f` 等 RSC 标记。
- **虎牙取流**：保留全部候选线路并按 hs.* 优先逐条安全探测（最多 4 条、整体 10 秒预算），失败记录脱敏主机与原因后切换，成功即返回。
- **中继时间线**：ClockEpoch 代际拼接——一次响应内大跳变/econnect 归零只建立一次共享偏移，旧音频尾部在另一轨确认新代际前丢弃，不再把旧数据套新偏移制造音画差；跨断点未确认代际 5 秒守卫避免永久饿死播放器；32 位输出时钟用尽时结束连接并提示重开会话。查询参数/Cookie 不进入诊断。
- **同步诊断**：`RelayTelemetry` 新增 `timeline_jumps` / `timeline_epochs` / `timeline_discarded_tags` / `clock_shift_ms` / `av_delta_in_ms` / `av_delta_out_ms` / `timeline_exhausted` / `policy_rejections` / `last_policy_reject`（全部 serde default，旧数据兼容）；会话页可直接显示，不需要额外协议。
- **一次重新同步**：会话管理器新增显式 `resync`，等待本会话播放器结束后按原播放器/画质/缓冲/弹幕选项重新打开；15 秒停止等待上限，失败回填可读错误，不会重复打开播放器。
- **弹幕恢复**：虎牙/抖音删除会话累计重连预算，改为连续失败计数 + 稳定接收 30 秒后复位 + 指数退避（上限 30 秒）；抖音 `LoginRequired` 等需要人工处理的错误仍明确停止。
- **弹幕规则**：用户屏蔽支持 `uid:`（正整数）、`name:`（忽略大小写）、`re:`（regex crate 线性引擎）与昵称包含；关键词高亮/置顶可在工作台编辑并生效；修复默认合并把 id 改成 `local-merge-N` 导致高亮断链；Small/Large 表情尺寸选择覆盖平台默认；启用 image 的 GIF/BMP 静态解码。
- **搜索与工作台**：查找主播支持分页“加载下一页”、粘贴直播链接/分享文案/uid 分流、来源摘录持久可滚动、切换查询/刷新/筛选清空旧选择、加入收藏要求平台核验完成、AI 重新搜索候选可见可选可核验、AI 忙时可取消；会话页停止/重新同步与中继计数；数据页扫描生产 logs 目录；收藏删除确认与 20 秒撤销；外链经系统 URL 入口且拒绝私网/带凭据地址。
- **验证**：release 构建通过；`cargo test --locked --offline` 全量通过（含 flv 时间线 19 项、弹幕规则契约、平台契约、GUI 契约等 48 个集成测试目标）；`Test-Preview` 462 文件哈希/清单/许可/隐私路径检查通过；包内 `--version` = 1.0.4、`self-test` 7/7。
- **未验证**：真实抖音房间取流（需登录/网页验证的房间）、真实长时音画同步与物理声画测量、多显示器/休眠/网络切换；这些在验收协议中列为待用户实机验证项。
