# 0.2.1 本地迁移预览

本版相对 0.2.0 完成“账号与登录”页的登录态自动复核；播放、中转、弹幕、覆盖层和观看会话行为不变。

- 打开“账号与登录”页时，对已保存凭据的平台自动调用各自官方健康接口；串行执行，每平台最多每 600 秒一次，显示状态、原因与“上次检查”时间。
- 自动检查在后台线程运行，尝试时间在请求前记录，网络失败不会逐帧重试；用户开始扫码/网页/手动检查时取消进行中的自动检查，并用代际标记丢弃旧结果，避免旧状态覆盖刚验证的新登录。
- 离线契约测试覆盖平台选择、检查间隔、时钟回退与检查时间文案；不联系平台，不读取账号。

0.2.0 的实测范围不变：B站扫码/官方登录有效/登录后弹幕；Rust 启动器→中转→mpv 实际视频、SC、全屏与点击穿透；PotPlayer 真实视频与弹幕；默认 500 连续失败预算的 503 次边界回归与一小时 8 路合成压测。

其他平台真实登录、付费 AI、PotPlayer 全屏/SC 穿透、多显示器及真实下播重开全周期仍未验收。本版仍是未提交的本地迁移预览，不附播放器、Cookie、密钥或个人资料，不改旧入口。
