# 0.3.11 本地迁移预览（四平台 PotPlayer/mpv 标题统一 + 探测兜底）

更新：2026-10-31。基线 0.3.10；数据与旧版兼容。

## 用户反馈与修复

- 用户要求：**所有平台、mpv 与 PotPlayer 两种播放器，窗口标题都必须是同一格式**：`<主播 - 直播间标题>  ·  <宽x高> <fps> <编码> <kbps>kbps`（与 mpv Lua 脚本一致）。
- **PotPlayer 标题探测兜底**：标题后缀优先通过中转连接读取 FLV onMetaData；若中转连接在启动瞬间未建立/边缘节点抖动失败，再直连解析出的上游 URL 探测一次；仍失败才保留基础标题，并写 `playback.log` 诊断。
- **抖音基础标题**：修复只会得到直播间标题的问题；解析页时同时取 owner/anchor 昵称，基础标题统一为 `主播 - 直播间标题`（与 B站/虎牙/斗鱼一致）。
- **虎牙别名房**：`huya:a16789` / `clkimmy` 等别名房先通过公开别名页解析数字 profileRoom，再取主播/标题；不再退化成“虎牙直播”。
- 四平台标题后缀字段统一为：宽x高、四舍五入 fps、h264/hevc 等短编码、接口/元数据视频码率；与 mpv Lua 的拼法逐字一致（两个空格 + · + 两个空格）。

## 验证

- 本机 PotPlayer 实测窗口标题：
  - B站 7777：`老实憨厚的笑笑 - 德云色 下午当铺耍起！  ·  1920x1080 60fps h264 8836kbps`
  - 斗鱼 633019：`啦啦啦不是狗狗狗 - 啦啦啦：上分模式！  ·  1920x1080 30fps h264 4000kbps`
  - 抖音 3010151431：`水姐（老公晚安） - 瓦手夜市  ·  1080x1920 60fps h264 7813kbps`
  - 虎牙别名 a16789：基础标题已恢复为“主播 - 标题”，后缀走同一探测路径。
- mpv 继续由打包 Lua 脚本使用相同 base + 技术参数格式；四平台 StreamHints 均已提供 anchor/room title。
- 离线矩阵/包复核见 docs/validation.md 与 notes/verification-r11.md（verifier 填）。

## 限制

- 平台未返回 onMetaData（例如纯 HLS/特殊容器）时无法得到分辨率/fps/码率，PotPlayer 只显示基础标题；这是信息源限制，不是格式不一致。
