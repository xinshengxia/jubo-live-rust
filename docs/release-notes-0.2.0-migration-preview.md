# 0.2.0 本地迁移预览

本版接通生产播放、登录与观看会话，并修复实际验收发现的问题：

- Windows分层覆盖层完成渲染却没有显示：设置统一alpha，并在样式重建后恢复；播放器退出后独立守卫回收覆盖层。
- PotPlayer报“服务器已关闭或地址错误”：其自有命令行解析将整项被引号包裹的标题当成视频URL。按原版 `/title="值"` 形式引用，视频与弹幕已确认恢复。

新增B站二维码、专属浏览器登录、官方会话健康、多观看会话、启动取消、下播等待与重播状态。中转默认500改为连续无效尝试预算，有效媒体进展复位且保留退避。

新增图片/WebP表情基础能力、礼物/进场、过滤/合并/延迟、前台播放器热键、跨平台搜索及可选DeepSeek原生联网研究。AI须在本程序手动配置独立密钥，新候选需要平台核验。

实测：B站扫码/官方登录有效/登录后弹幕；生产Rust中转到mpv实际视频、SC、全屏与穿透；PotPlayer视频/弹幕；默认配置一小时8路合成压测及503次有效重连边界。见validation.md。

其他平台真实登录、付费AI、真实下播重开全周期、PotPlayer全屏/SC穿透、多显示器及原版全部富媒体/样式仍未验收或未迁移。本版不是完整功能对等版本。

不附播放器、Cookie、密钥或个人资料，不改旧入口。升级保留独立Rust数据；回退前保留兼容配置快照。仍为未提交的本地开发预览，无commit/push/远端发布。
