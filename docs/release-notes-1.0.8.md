# 1.0.8（2026-11-09）

修复「我的收藏」页“格式说明”点击后没有可见反馈，以及「查找主播」页 DeepSeek 设置里找不到 API Key 填写位置。

## 根因与修复

- **格式说明**：旧实现只把说明文字写入窗口底部 11px 状态栏。点击位置在启动卡片右上角，状态栏离得很远，且这段文字与收藏页其它提示相近，用户会认为“什么都没发生”。现在点击即打开居中的“房间输入格式说明”对话框，列出房间号 / 官方直播间链接 / 平台:房间三种写法与示例；关闭按钮与 Esc 均可关闭，链接本身增加悬停提示。
- **API Key 找不到填写位置**：旧实现把 AI 设置做成「查找主播」页内的固定高度内联面板；API Key 只有一个默认宽度（约 280px）的密码框和灰色提示文字，没有字段标签，也不随页面滚动定位，很容易被当成说明文字。现在：
  - “DeepSeek 设置”和 AI 搜索区新增的“填写 API Key”都会打开独立的“DeepSeek AI 设置”对话框；
  - API Key 增加明确字段标签、整行输入框与“显示/隐藏”切换，并提示留空表示保留已保存的密钥；
  - 未配置密钥时点击 AI 搜索会自动打开该对话框（不会发起计费请求），页面的 AI 区域同时显示橙色“未配置 API Key”提示和“填写 API Key”按钮；
  - 对话框内提供“打开 DeepSeek 开放平台”按钮，经既有 `public_external_url` 校验后调用系统浏览器；保存/清除逻辑与旧版一致（Windows DPAPI 加密，不读取原版、DSH 或浏览器中的密钥）。
- Esc 关闭当前对话框；所有切换页面的入口（侧边栏导航、“弹幕设置…”、“全部会话 →”、“查看诊断日志”、核验完成填入启动卡片）都会关闭上述对话框，避免隐藏状态残留。

## 验证

- 新增离线回归（headless egui，无窗口/网络/用户数据）：格式说明文本契约（三种写法，8 个示例均被 `Target::parse` 接受）；真实点击「格式说明」链接与「DeepSeek 设置」按钮的入口路径；API Key 字段在真实 egui 帧中接收键入文本；未配置密钥时 `start_ai` 只打开对话框、不进入 busy/不发起请求；切页统一关闭对话框并清除旧结果；AI 保存/清除结果回显到对话框。
- 离线全量测试与运行态验证记录见 `docs/validation.md` 的 1.0.8 段。
- 未验证：真实 DeepSeek 计费请求（本次未配置真实密钥、未调用远程接口）；真实桌面多显示器/混合 DPI 下的对话框位置。

## 已知边界

- 本版只调整界面入口与提示，不改 AI 请求协议、密钥存储格式和平台搜索逻辑。
- 旧版数据目录无需迁移；API Key 保存位置与加密方式不变。
