# 0.2.4 本地迁移预览

本版补齐设置页的播放器/工具路径选择体验，修复“只能手填且错误路径静默保存”的问题。

- 设置页「播放器与解析工具」三个字段（mpv / PotPlayer / yt-dlp）新增：
  - 「浏览…」：Windows 原生文件选择对话框（comdlg32 GetOpenFileNameW，raw FFI，不新增依赖；取消/失败不影响界面）。
  - 「自动检测」：按 程序同级 → bin → bin/mpv → PATH → Program Files / LOCALAPPDATA（mpv、DAUM\PotPlayer、yt-dlp）顺序查找，找到即填入。
  - 实时状态：路径有效 / 具体错误（相对路径、不存在、非普通文件、过小）/ 留空自动查找。
- 「保存路径」先整体校验三字段；任一失败只在状态栏报明确原因且不覆盖已保存配置，避免像旧版那样相对路径/坏路径看起来“已保存”。
- 相对路径（如 tools/yt-dlp.exe）现在会被明确拒绝并提示改为绝对路径或使用浏览。
- 原生对话框的实际打开/选择需 GUI 实机确认；自动检测在真实安装目录的命中由合成测试覆盖，实机待确认。

其余功能与 0.2.3 相同（弹幕/SC 富媒体与布局、SC 选择性命中、彩色 emoji 随包、登录健康时效、本地数据/平台状态页、开播徽标、重播语义、mpv 标题 Lua、发布流水线、性能优化等），未验收项不变。
