# 1.0.0

本版修复头像与搜索流程中的五项缺陷：

- 头像在完整解码前检查容器尺寸，并限制解码分配；候选头像在后台缩为 48px，避免大图在界面线程解码或创建超大纹理。
- 下载完成时立即释放请求名额，旧查询不再占住名额。候选图片、纹理和失败重试缓存各有容量限制，最多同时处理 4 项候选头像请求。
- 缓存搜索也会复位旧核验状态；过期响应继续被丢弃。
- 普通查询的取消操作同步取消 AI 等待并清除忙碌状态；已发出的服务请求仍可能计费。
- 缓存图片缺失、损坏、尺寸或路径异常时移除失效索引，后续请求可以重新下载。

验证使用合成图片、临时目录、替代网络接口和无窗口 egui 输入事件，不代表完成真实平台登录、长时播放或付费服务验收。保留原有独立数据目录和登录凭据。

本版库测试 319 项通过（含 6 项新增回归），4 项按原定义忽略；2 项依赖系统 TCP 所有权权限或外部 DNS 的测试未运行。发行程序的 7 项离线自检、版本、能力元数据和房间地址解析通过；程序包的文件清单、SHA-256、必需资源和已知私有路径检查通过。
