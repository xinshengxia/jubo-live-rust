# 验证范围

1.0.0 的修复树已通过 319 项库测试，包括 6 项头像与搜索取消状态回归。4 项测试依原定义忽略；2 项需要系统 TCP 所有权权限或外部 DNS 的测试在受限环境未运行。发行程序的 7 项离线自检、版本元数据、能力清单和房间解析通过。

本次公开源码在该修复树上剥离了本机路径、内部文档与个人诊断脚本，彩色 emoji 图集改为许可明确的 Noto Emoji。公开提交构建和图集验证结果以 v1.0.0 的 Release 说明为准。

离线测试不能证明真实平台当前可播放或登录有效。长时间播放、真实扫码/网页验证、付费 SC、付费 AI、多显示器和全部播放器组合不在本次公开发布验收范围。没有随仓库上传截图、账号或真实观看数据。
