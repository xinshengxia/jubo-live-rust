# 验证范围

1.0.1 的修复树已通过全量离线矩阵（44 个 test target，`--locked --offline`）：默认 GUI 626 passed / 0 failed / 27 ignored，`--no-default-features` 422 passed / 0 failed / 26 ignored，两套退出码均为 0。新增 4 项库测试；2 个新增验收测试默认离线（真实网络需显式 opt-in，默认矩阵忽略）。

本版修复抖音弹幕图片表情：连接抖音时后台拉取 `emoji/list` 表情字典并缓存，覆盖层按缓存代次刷新并把方括号表情码渲染为图片。真实表情为 VP8L 无损 WebP（96×96），由既有 `image`/`image-webp` 解码路径处理；拉取、超限或解码失败只回退为文字，不影响弹幕接收。另修正一条 1.0.0 遗留的全量测试契约断言，不涉及用户功能。

真实匿名接口实测返回 214 条表情（含 `[捂脸]`/`[微笑]`）；真实直播间匿名连接后覆盖层把弹幕表情绘制为图片，并在本机保留渲染证据（截图不随仓库上传）。

本次公开源码在 1.0.0 公开发布树上剥离本机路径、内部文档与个人诊断脚本；彩色 emoji 图集仍为许可明确的 Noto Emoji。公开提交构建与图集验证结果以 v1.0.1 的 Release 说明为准。

离线测试不能证明真实平台当前可播放或登录有效。长时间播放、真实扫码/网页验证、付费 SC、付费 AI、多显示器和全部播放器组合不在本次公开发布验收范围。没有随仓库上传截图、账号或真实观看数据。
