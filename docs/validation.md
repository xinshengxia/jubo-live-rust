# 验证范围

1.0.2 的修复树已通过离线检查：`cargo check --locked --offline` 通过；`flv` 模块单测 14/14（含 2 个新增时间戳重基测试）；中转、重连、日志与播放器计划契约测试 31 passed / 0 failed / 4 ignored，EXIT=0（4 个 ignored 均为显式 `#[ignore]` 性能类测试，不在默认矩阵运行）。

本版修复 PotPlayer 等播放器观看时反复「缓冲」问题中属于中转一侧的两个放大因素：同一 HTTP 响应内上游跳到直播边缘产生的大时间戳跳变改为重基为连续时钟（音视频共用，+20 ms 续接；被上游跳过的内容仍缺失，播放器时钟不断裂）；播放器写超时 5 秒→15 秒；上游正常媒体分段结束后重连等待 1 秒→150 毫秒。运行态只读观测：健康时段两只独立读取合计 440 秒无 >1 秒到达空档，播放器读缓存模型（2 秒）与 15 秒模型各 480 秒均 0 次欠载；出现「缓冲」的时间段对应上游网络短时降速，程序侧无法提升带宽，只缩短恢复窗口并避免播放器时钟断裂。

本次公开源码在 1.0.1 公开发布树上只增加上述修复与版本文档；未加入本机路径、维护记录、用户数据或截图。公开提交构建与验证结果以 v1.0.2 的 Release 说明为准。

离线测试不能证明真实平台当前可播放或登录有效；长时间播放、真实扫码/网页验证、付费 SC、付费 AI、多显示器和全部播放器组合不在本次公开发布验收范围。
