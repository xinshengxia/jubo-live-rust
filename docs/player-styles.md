# 播放器外观

打开「播放器与画质」，选中 mpv 或 PotPlayer，在「播放外观」选择样式。两个播放器单独保存选择。新装和升级默认均沿用各自播放器的设置。正在播放的窗口继续使用启动时选定的外观。需要用 1.0.12 打开同一份数据时，先在新版中将两个播放器都切回「沿用播放器设置」。

## mpv

选择「ModernZ ＋ 缩略图」启用独立配置目录中的中文控制栏、Fluent 图标和橙色进度条。悬停进度条可查看已采样的小图。不可寻址直播按约 2 秒间隔采样，普通网络点播约 5 秒。会话临时文件在换片或正常退出时清理。按 320×180 每两秒一张估算，每小时约 396 MiB，实际占用随窗口与取样情况变化。直播可跳转的范围由音视频缓冲决定。切回「沿用播放器设置」会恢复使用 mpv 自己的脚本、字体和配置。两种模式均保留启动器的直播播放参数、标题与刷新功能。

## PotPlayer

选择「Fluent Glass」后，下次打开直播时会准备独立的 64 位 PotPlayer 及其皮肤设置。首次构建需要已安装 PotPlayer x64（含默认皮肤）、可用的 64 位 Python 3.10+ 和网络。已有匹配的橙色 Fluent Glass 成品时可直接离线复用。播放器与构建产物保存在当前用户的本地应用数据目录，后续使用准备好的副本。切回「沿用播放器设置」即使用之前指定的 PotPlayer 和它自己的设置。

源程序、图标与许可证均随软件提供。PotPlayer 使用自身的进度条预览机制。第三方组件与来源详见[第三方声明](../THIRD_PARTY_NOTICES.md)。
