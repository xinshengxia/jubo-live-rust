# 0.3.8 本地迁移预览（抖音解析路径 / 收藏名称回填 / 无乱码 / 直播优先）

更新：2026-10-31。基线 0.3.7；数据与旧版兼容。

## 用户反馈与修复

1. **抖音“解析不成功”**（用户提供原版成功截图：coke老师 → 989125753255）：补齐原版 C# 的解析路径 **账号资料 → 抖音号 → 直播页 → 数字房间**。Rust 现在会用账号资料里的抖音号抓取 live.douyin.com/<抖音号> 页面的 SSR roomStore，取内部场次后走公开 reflow 得到数字 web_rid；核验时未开播也直接绑定 live.douyin.com/<web_rid> 并标注“核验时未开播，可直接收藏”。真实登录态实测 coke老师/程潇/小可乐coke 等候选均解析成功（如 989125753255）；仍需账号公开页提供 roomStore，否则保持明确失败提示。
2. **收藏名称不回填**：查找页单击选中候选时，自动把候选昵称填入底部“收藏名称”输入框（保留用户已有自定义名的逻辑与编辑能力），与 C# 版一致。
3. **介绍文字乱码/豆腐块**：平台简介中的 emoji（🧣、🛰️ 等）在不带彩色 emoji 字体的 UI 中显示为方框。现在渲染层只对显示文本做 emoji 剥离（数据原样保留），候选行/详情不再出现方框。
4. **搜索结果可能性排序**：候选仍按原版 Tier（线索匹配/同名/别名/关键词）排序，第三行显示“可能性高/中/低”及原因，排序依据一眼可见。
5. **收藏页正在直播优先**：对齐原版 FavoriteRank，收藏卡片按 正在直播 → 重播 → 未开播 → 状态未知 排序，同档按名称稳定排序；badge 结果返回后自动重排。

## 验证

- cargo check --all-targets EXIT=0；cargo test --lib **307 passed / 0 failed / 2 ignored**（新增显示文本清洗/排序标签/徽章排序单测）。
- 真实登录态抖音核验：coke 搜索候选逐一 verify，coke老师 等返回 room 989125753255（offline，可收藏）；不再只报“未返回直播场次”。
- 其他：B站/虎牙/斗鱼路径不变；头像索引迁移与 remembered URL 保持 0.3.7 状态。

## 限制

- 抖音账号公开页若不提供 roomStore（私密/风控），仍无法离线绑定数字房间；需要开播或直播分享链接。
- 收藏徽章排序依赖后台状态查询；查询未返回前按“状态未知”处理，不伪造正在直播。
