# 1.1.1 · mpv 全屏弹幕显示

本版修复 Windows 上部分 mpv 全屏会话只剩弹幕、视频区域变黑的问题。弹幕继续由原有引擎绘制，Windows 使用逐像素透明位图将结果叠到 mpv 上。窗口切换、最大化和全屏时，弹幕和醒目留言的点击区域会跟随播放器。PotPlayer 沿用原来的弹幕显示方式。

复发时记下本地时间。「观看会话」可查看播放器状态，程序的数据目录中还会滚动保留弹幕提交计数、最近一帧的时间间隔和可取得的 mpv 同步、掉帧、缓存指标，便于对齐故障前后的情况。

已安装 1.1.0 的用户可以在主界面检查更新，也可以下载并完整解压便携包。需要单独安装 mpv 时，推荐 shinchiro 最新可下载的普通 Windows x64 构建。[播放器设置](tool-setup.md)
