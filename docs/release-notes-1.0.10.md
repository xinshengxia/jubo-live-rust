# 1.0.10 更新

- 主播查询支持用 B 站直播间链接核验主播。虎牙、斗鱼按账号与房间归属确认结果，重新核验失败后会撤销旧资格。抖音网页辅助可读取用户在专属窗口中执行的当前关键词搜索。
- 房间状态处理区分重播、未知和等待网页验证。抖音同页出现空房间占位时继续查找有效房间。虎牙网页样式中的重播类名不再决定房态。
- 收藏和历史按房间身份保留选择。导入会报告跳过的无效收藏。界面字体、缩放、深色模式和自动带起弹幕开关独立保存，本次播放的选择不会随其他设置写入。
- 会话重新同步保留本次播放设置。mpv 在中文临时目录下也能使用标题与刷新脚本。B 站高清回退按画质档位选择，直链播放可重新解析。
- 礼物事件沿用发送者 UID 屏蔽规则。独立送礼按次数累计，连击更新按平台总数合并，已过期的条目及时释放显示位置。

本版按离线测试和合成输入验证。真实平台验证、账号权益、两小时播放和外接显示设备的表现取决于具体环境。
