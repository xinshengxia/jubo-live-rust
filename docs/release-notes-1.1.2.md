# 1.1.2 · mpv 弹幕局部更新

本版减少了 Windows 上 mpv 弹幕覆盖层的像素传输。GPU 仍绘制完整画面。在支持局部读回的设备上，弹幕滚动、醒目留言变化或提示消失时，程序只读回新旧位置涉及的像素，写到已保留的叠加位图中，再把覆盖这些变化的一个矩形提交给 Windows。首次绘制、窗口尺寸或缩放变化时会刷新整幅位图。像素读回缓冲区不可用时使用整帧传输。静止画面可以跳过重复提交。

mpv 继续使用逐像素透明位图显示弹幕。PotPlayer 继续使用原有的弹幕显示方式。用户可以在主界面检查更新，或下载并完整解压 Windows x64 的 lite 包。[播放器与外观设置](player-styles.md)
