## 1.0.4 修复摘要（2026-11-06）

本轮按 C# 1.1.5 对照审计补齐取流、弹幕、搜索工作台与音画同步链路，构建后离线回归与打包校验通过：

- 抖音媒体重定向：结构化拒绝诊断（rule/stage/host/status，日志与遥测只留脱敏主机），CDN 白名单补齐实际家族并支持 http→https；房间页 IPv4 优先、系统解析回退、空壳页重试与 6/12/18 秒冷却、保存 Cookie 时补新 nonce。
- 虎牙取流：保留全部候选线路并按 hs.* 优先逐条安全探测（≤4 条、整体 10 秒预算），失败记录主机与原因后切换。

- 弹幕：虎牙/抖音断线恢复改为连续失败预算并在稳定接收后复位；用户屏蔽支持 uid:/name:/re:/包含匹配；高亮/置顶可编辑且修复合并 ID 断链；`re:` 改用 regex crate 线性引擎，非法/不支持语法明确报告；GIF/BMP 静态解码；Small/Large 表情尺寸选择生效。
- 搜索与工作台：搜索分页、粘贴链接/分享/uid 分流、来源摘录可滚动、切换查询清旧选择、收藏核验门槛、AI 新候选可见可选可核验、会话页停止/重新同步与中继计数、数据页覆盖生产日志、收藏删除确认与撤销、外链安全打开。
- 本机包：1.0.4，`--version` 与 `self-test`（7/7）通过，Test-Preview 462 项文件哈希校验通过；真实抖音房间、真实长时音画同步与多显示器场景仍需用户实机验收。

## 0.3.2 登录浏览器隐私修复（2026-10-31）

- 网页登录窗口优先使用本机 Chrome 的全新临时资料，避免 Edge 的 Windows 账户隐式登录与 Microsoft 同步弹窗；仅无 Chrome 时回退 Edge 并关闭 sync/implicit-signin/first-run 特性。
- 登录仍走独立 profile + 本进程专属 DevTools 端点（端口所有者校验）→ 平台接口核验 → DPAPI 加密保存；不读取日常浏览器资料。
- 未验证：真实扫码登录全流程、Edge-only 机器同步提示的实际表现。

## 0.3.13 覆盖层交互修复（2026-11-01，用户实测 6 项）

- **有 SC 时偶发不穿透 / PotPlayer 全屏底部控制栏不出现**：原「有卡片时清 WS_EX_TRANSPARENT + WM_NCHITTEST 返回 HTTRANSPARENT」的跨进程丢输入问题；改为覆盖层主窗恒透明 + 独立 alpha-0 输入窗（window region = 卡片/关闭/滚动条矩形并集）+ 卡片区 WM_MOUSEMOVE 转发播放器；命中矩形裁剪到可见带。
