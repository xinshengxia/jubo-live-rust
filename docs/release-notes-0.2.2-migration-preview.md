# 0.2.2 本地迁移预览

本版是相对 0.2.1 的一次较大对等补齐：弹幕/SC 富媒体与布局、登录健康时效、本地数据与平台状态页、开播徽标、会话信息、重播取流语义、mpv 标题/控制条提示、便携布局与诊断入口，并给出可复现的性能基线与优化。

## 弹幕与 SC

- 四平台富媒体解析：勋章/用户等级/守护/舰队、图片表情尺寸与大表情占位、SC 服务端配色与头像、观众等级、公告/点赞/人数统计事件；B站真实 DAnmu 布局字段。
- 弹幕布局：固定顶/底分区与每类上限、过长固定弹幕转滚动、逆向弹幕、与 SC/安全区整带避让、窗口/字号变化重新测量并保留飞行进度、令牌桶短队列与拥挤缩小、重复弹幕归一合并。
- SC 卡片：完整/紧凑/角标/关闭四形态、四角、缩放与时长倍率、头像、4px 生命周期进度条；点击卡片/滚动交互仍随覆盖层鼠标穿透（未实现）。
- 文本表情字典解析与运行时拉取缓存（可本地 LIVE_HUB_EMOTICON_JSON）；彩色 emoji 清单解析与本地精灵图加载（LIVE_HUB_EMOJI_SHEET，缺省降级）；emoji 精灵图不随包。
- 设置页接线全部新增弹幕/SC 字段，旧 state.json 向后兼容。

## 账号、工作台与搜索

- 登录健康：有效超过 10 分钟转「上次有效，待复查」，启动/新凭据自动复核，手动重试 10 秒下限，凭据指纹作废旧结果；账号页显示详情与最近观测。
- 新增「本地数据与平台状态」页：收藏/历史/配置/缓存/日志只读清单与明细、配置投影、缓存日志清理、分平台退出、Build 信息、房间/播放/弹幕最近观测与 5 分钟规则。
- 收藏/最近播放开播徽标 [播]/[休]/[重播] 与选中即查（一次最多 4 个在途、每房 2 分钟、未知 20 秒重试、未知不冒充未开播）。
- 会话页增加画质/缓冲/播放器列，「重新打开」保留原播放器与缓冲；播放页可直接取消启动/停止。
- 主播查询：补充线索、按平台 10 分钟缓存与刷新、别名/公会前缀排序；抖音账号语法（主页 URL、sec_uid、抖音号:）本地识别。

## 播放

- mpv 标题/控制条：移植原版 live-title.lua / live-resync.lua，写 base/media/relay 提示；窗口标题包含分辨率/fps/编码/码率（mpv 能提供的部分），底部控制条标题带本机日期时间；[重连中]/[已下播]/重播流不可用由中转状态驱动 OSD。
- 重播取流：虎牙页面重播标记、斗鱼 show_status/videoLoop 分类、抖音仅 status=4 判下播；平台专有轮播/重播/录播文案与 REPLAY-UNAVAILABLE 语义（真实重播房间待验收）。
- 便携布局：exe 旁存在 bin/mpv/mpv.exe 或 portable.marker 时数据目录=edge 旁 data\，否则 %LOCALAPPDATA%\LiveHubRust；--data-dir 仍优先。
- 诊断：stream-info（别名 streaminfo，onMetaData + 实测窗口）、ui-probe（无窗口离线探针）、有界脱敏运行日志 <data>\logs\live-hub-rust.log（256 KiB、轮换 1 份）。

## 性能（release，本机中位）

| 指标 | 优化前 | 优化后 | 提升 |
| --- | --- | --- | --- |
| 中转小 tag（20k×256B） | 2,822 tags/s | 360,203 tags/s | 127.6× |
| 中转 32KiB tag | 1,420 tags/s / 43.4 MiB/s | 4,373 tags/s / 137.5 MiB/s | 3.08× |
| FLV tag 解析（中转路径） | 7.81M tags/s | 13.34M tags/s | 1.71× |
| C# vs Rust 冷启动+离线自检 | C# 1194.05 ms | Rust 136.44 ms | Rust 快 8.75× |

优化：上游 64 KiB BufReader、去掉每次 socket read 的玩家存活探测、FLV tag 缓冲复用、玩家写合并。C# 无 parse/FLV/弹幕/中转离线入口，这些项不做跨语言换算并已在测量文档逐项标注。复测脚本与原始数据在本机验收目录。
