# 1.0.5

修复搜索、队列、快捷键和会话恢复的边界问题：

- 搜索分页按平台保存页码；受阻的平台重试原页，已成功的平台继续向后加载。
- 候选核验与搜索、AI 使用独立代次，选择候选不再使其他请求丢失完成通知。
- 队列满时从最低优先级消息中淘汰最早一条，避免仍有聊天时误丢 SC。
- 固定 F7–F10 注册冲突后定期重试未持有的键；失焦或停用后忽略排队的旧按键。
- B站 UID 经官方账号与房间归属核验；外部取流工具回退使用受保护临时文件传递本程序凭据，子进程退出后删除。
- 停止与重新同步忽略迟到的旧状态，重开成功后再报告恢复完成。
- 观看会话显示时钟跳变、代际、丢弃旧包和包时间戳差，支持标记音画异常。包时间戳差不等于物理输出同步测量。

完整礼物、点赞和进场事件、全量动态表情仍未覆盖。GIF 支持为静态首帧。真实平台兼容性、长时声画输出与系统热键交互需要另行实测，离线测试不代表上述项目全部通过。
