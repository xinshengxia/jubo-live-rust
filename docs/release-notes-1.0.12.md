# 看直播 Rust 1.0.12

- 关闭“等待开播”时，中继记住当前会话已确认的下播状态。播放器重复连接会直接收到 HTTP 410，手动新开房间会重新查询。虎牙仅返回空流列表时显示房态待确认。
- 收藏和最近播放区分查询中、直播、重播、下播和状态待确认。查询失败可悬停查看原因及本次启动内上次确认的房态。
- Windows 输入法选词回车由输入法处理。主播搜索框保留焦点，独立按回车查询一次。网页辅助和 DeepSeek 收进“更多查找方式”。
- 小窗口下收藏改为可滚动的紧凑列表，弹幕显示和 SC 设置按可用宽度排列。首次使用可从首页选择或自动查找播放器。
- PotPlayer 画面定格时，可在“观看会话”选中对应房间，点击“一次重新同步”。本版未引入实验性的延迟缓冲队列。

Windows x64 用户下载 lite 包，完整解压后打开。升级请沿用原数据目录。实际输入法组合以及 PotPlayer 两小时连续播放仍需实机验证。
