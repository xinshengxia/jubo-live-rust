# 0.3.15 本地迁移预览（收藏页右侧「正在观看 / 最近打开」列表修复）

更新：2026-11-01。基线 0.3.14；数据与旧版兼容。

## 修复（用户实测反馈）

### 收藏页右侧列表看不到正在看的会话、且溢出时没有滚动条 / 滚不动

- 现象：正在播放的会话不在右侧列表里（要往下才能看到但看不到），列表内容超出面板后没有滚动条，滚轮也不能滚。
- 根因（两处）：
  1. `SessionManager::snapshots()` 已经按开始时间**从新到旧**排序，界面又做了一次 `.rev()`，把最新的（正在看的）会话排到了列表最底部；列表溢出后它正好在可视区外。
  2. 列表用 egui `ScrollArea` 包着，但每一行是按计算坐标绘制的、**没有向布局申报高度**；ScrollArea 只按布局申报的内容高度决定滚动范围，于是内容高度≈0：既不出现滚动条，也滚不动，超出的卡片被直接裁掉。
- 修复：去掉多余的倒序（最新/正在看的排最前）；每行先 `allocate_exact_size` 申报高度再绘制，列表恢复可见滚动条与滚轮滚动；同时按原版 `Platform:Room` 去重（同一房间多次打开不会重复出现，改为最新一条），历史记录仍排在会话之后、按最近时间顺序。
- 兼容：右侧列表的行数上限对齐原版（24 条）；「重新打开」「全部会话 →」行为不变。
