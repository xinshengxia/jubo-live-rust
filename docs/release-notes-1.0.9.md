# 1.0.9 修复候选（2026-11-17）

修复独立浏览器初始进程退出或交接后，窗口仍在却无法保存登录的问题；补全播放器、快捷方式和可选工具配置。候选版的真实平台验收、干净机器与长时同步范围见下文。

## 变化

- 专属浏览器在恢复运行前加入本次会话的 Windows Job。捕获前检查进程链、创建时间、可执行文件、专属 profile 文件、回环端口和 WebSocket 身份；初始进程退出不再直接判窗口关闭。取消只关闭本次进程链，不接管日常浏览器，不删除用户 profile。
- 网页登录自动定期检测，也保留手动重试。B站二维码到期自动刷新。抖音网页验证和账号登录分别判断，账号核验有效才保存；保存前复查候选，核验期间凭据变化则丢弃旧结果。网络未知和验证未完成不覆盖旧凭据。参考 C# 版登录逻辑，Rust 仍保留独立实现与 DPAPI 存储。
- mpv / PotPlayer / yt-dlp 接受程序、粘贴路径及 `.lnk`；浏览与拖入使用同一解析、检测和保存流程。只读快捷方式的真实目标，不执行链接、不继承其参数或工作目录。失效目标、脚本、网页和安装器包装明确报错。
- 主播放器卡片提供自动查找、检测并保存和获取入口；版本、OpenAL 能力、保存结果就近显示，不再把非空路径当“已就绪”。多候选供用户选择，既有路径先复查。
- yt-dlp 明确为 B站原生解析部分失败时的可选回退。已有程序直接选择；缺少时由用户触发从官方固定 Release 下载，校验大小与 SHA-256 后配置到应用数据目录。支持进度和取消，失败保留旧配置，不安装 Deno/FFmpeg、不改 PATH。
- 首页先展示下载和三步使用；直接列出四平台登录影响，历史变更移出主说明。移除公开树中残留的个人诊断脚本，保留其本地副本。

## 兼容 mpv 获取

安装 mpv 时，请参阅[当前推荐的 Windows x64 构建与安装方法](tool-setup.md#mpv)。

**1.0.9 发布时的验证记录。** 当时使用 shinchiro 的 20261021 Windows x64 构建，mpv 版本为 `v0.41.0-1227-ge471496c5`，`--ao=help` 列出了 OpenAL。该归档的 SHA-256 为 `4a355f3e89c83fabc730d33fb4e759dfec747806ed2287b61a90d1681b83e8d3`。[历史构建发布页](https://github.com/shinchiro/mpv-winbuild-cmake/releases/tag/20261021)

## 发布包与升级

本轮只提供 Windows x64 **lite** 与源码 ZIP，不捆绑播放器或 yt-dlp，也没有 full 包。已安装的工具可直接复用。各 ZIP 附 SHA-256，程序未签名。

yt-dlp 官方项目：**[yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp)**。它是 B站部分取流失败时的可选回退，已有程序可以直接配置，不要求重新下载。

升级前保留旧版完整目录和用户数据；解压到新目录，再使用原数据目录或手动迁移便携 `data/`。本次不改变凭据格式，DPAPI 不保证跨电脑解密。[数据优先级与操作步骤](getting-started.md)

## 验证边界

- 全量离线回归 760 passed / 0 failed；随后界面调整再次通过 436 项库测试和 56 项 GUI / 设置 / 登录契约。默认测试使用合成数据和隔离目录，忽略的真实环境项目不算通过。
- 用户完成真实抖音扫码，应用核验有效并加密保存；独立进程重新读取本机 DPAPI 凭据并经官方只读接口复核有效。其他平台的本版真实登录仍待分别验证。
- 兼容 mpv 的版本、OpenAL 能力探测和应用同一策略下 1 秒合成静音 WAV 初始化 / 正常 EOF 通过；上游归档摘要已核对。这不代表真实直播长时同步已通过。PotPlayer、全平台登录前后观看 / 画质 / 搜索 / 弹幕对照仍需分别验收。
- 新播放器页减少常驻说明与按钮，yt-dlp 默认收起，播放偏好统一分组；常规与最小窗口布局已检查。
- 若浏览器被系统服务重新启动并脱离本次受控进程链，应用仍拒绝自动读取，需关闭旧专属窗口再重新打开；不会为恢复体验而关联日常浏览器。
- 干净 Windows 标准用户、无预装工具环境及至少两小时真实直播音画同步仍待验收。未完成这些条件前作为修复候选发布，不冒充全场景验收的稳定版。
- 平台接口、网络和风控可能变化；登录有效不保证解锁全部画质或所有请求。下载入口固定受维护版本，可能需要后续更新。
