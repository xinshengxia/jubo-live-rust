# 1.0.1

修复抖音直播弹幕图片表情不显示：Rust 版此前只接了 B站 房间表情字典，抖音 `emoji/list` 解析函数虽然存在但从未被调用，`[捂脸]` 一类平台表情码只能按原始文字显示。

本版在连接抖音时后台拉取并缓存平台表情字典，覆盖层按缓存代次刷新后把表情渲染为图片。真实抖音表情为 VP8L 无损 WebP（96×96），走既有的有界远程图片解码路径；拉取失败、响应超限或解码失败只回退为文字，不影响弹幕接收。换房间或切平台时字典也会刷新。本地 `LIVE_HUB_EMOTICON_JSON` 离线验证入口同时接受抖音与 B站 两种字典响应形状。

另修正 1.0.0 遗留的一条全量测试契约断言（能力清单 stage 已是 `release`），不涉及用户功能。

验证：全量离线矩阵默认 GUI 626 passed / 0 failed / 27 ignored，`--no-default-features` 422 passed / 0 failed / 26 ignored（44 个 test target，EXIT=0）；真实匿名接口 214 条、真实直播间覆盖层渲染通过（本机留证，不上传截图）。

下载 lite ZIP 后需自行安装并选择 mpv 或 PotPlayer；程序未签名；真实平台与硬件组合的验收范围见 validation.md。
